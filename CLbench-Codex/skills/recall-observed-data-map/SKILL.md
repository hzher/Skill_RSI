# 使用本会话已经查到的数据地图

题面后如附有数据地图，条目均来自同一会话、当前数据版本中较早的真实 QUERY 回执。用其中已经覆盖的字段和类别定位相关表，尽量把下一次真实查询用于本题的计算。若一个类别分布在多表，查询所有相关表。

字段清单只说明已经看到了哪些定义。分类映射只覆盖曾完整分组的表与字段。缺少所需字段、单位、候选表、资格口径或出现相互冲突的回执时，从真实数据库核实。遇到新会话、数据或模式变更通知时重新建立映射。

地图不提供上题答案或评分，也不替你确定缺失值怎样进入当前题的分母。每条实际发出的查询均经过原生工具并占用原查询预算。使用原生 ANSWER 提交本题的结果。
