# 在连续查询中复用已见表定义

每道新题先从当前线程找出本题需要的表、字段和关联键，以及上一次真实目录查询返回的定义。快照仍相同、所需定义可见时，下一条查询直接计算本题的业务值。

一次完整目录读取可以支持后续的表选择。只看到部分表时，只沿用确实返回过的定义；仍有缺口就只查所需的表。达到返回行数上限、输出被截断或上下文里只剩下猜测时，重新确认缺失部分。

新会话、新数据库、变更通知或与已见定义矛盾的错误都会使原有依据失效。从当前快照重新取证。表结构可以说明有哪些列，价格单位、字段覆盖、当前数据值和最终答案仍要由本题的业务查询确定。每次实际发出的查询都按原接口执行并计入本题预算。
