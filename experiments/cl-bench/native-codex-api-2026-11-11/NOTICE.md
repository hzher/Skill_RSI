# 来源与许可

本包是实际 CL-Bench 实验过程及结果的整理副本，源提交和逐文件摘要见来源清单。CL-Bench 来源为 `config/sources.lock.json` 所列固定仓库与未合并候选；上游 Apache-2.0 许可原文保存在 [licenses/CL-Bench-LICENSE](licenses/CL-Bench-LICENSE)。

原生轨迹中的题目内容、仓库片段、生成补丁和相关第三方材料保留其原有来源及适用许可；复制实验结果不等于将其统一重新许可为目标仓库的 MIT。未附带第三方完整源码仓库、独立任务数据集或私有服务配置。

新写说明只使用项目名、版本和技术标识；原始数据中的任务 ID、公开仓库标识、调用/会话 ID 和必要版权声明保留，用于核对真实执行。
