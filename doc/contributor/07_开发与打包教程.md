# 用 Conda 开发和打包 Skill RSI

开发者修改源码，交付给用户的是一个 `.whl` 安装包（wheel）。自己试用时也安装这份文件，看到的就是用户收到的功能。

## 1. 首次创建开发环境

安装好 Conda 后，在含有 `pyproject.toml` 的仓库根目录运行下面两行。环境名为 `skill-rsi-dev`，自带 Python 3.14 和构建工具。以后打开新终端，只需执行第二行。[开发环境配置](../../environment-dev.yml)

```sh
conda env create -f environment-dev.yml
conda activate skill-rsi-dev
```

## 2. 修改代码，构建安装包

改宿主适配器时，进入 `skill_rsi/adapters/<宿主名>/`。改内置策略时，进入 `skill_rsi/components/resources/<策略名>/`。保存后在仓库根目录构建安装包。

```sh
python -m build --no-isolation --outdir dist
```

构建工具使用当前 Conda 环境，先生成源码包 `.tar.gz`，再从源码包构建 wheel。以 0.2.0 为例，交给用户的文件是 `dist/skill_rsi-0.2.0-py3-none-any.whl`。正式发新版前，更新 `pyproject.toml` 的 `project.version`。已发布策略的内容有改动时，也要更新其 `manifest.json` 中的 `version`。

## 3. 安装刚构建的 wheel

在同一个 Conda 环境、同一个仓库根目录运行。安装时填写本次构建输出的完整文件名。`--force-reinstall` 让你在本机反复打磨同一个开发版本时也能装上最新改动。

```sh
python -m pip install --force-reinstall ./dist/skill_rsi-0.2.0-py3-none-any.whl
skill-rsi --version
skill-rsi artifact catalog
```

第一条查询命令应显示 `skill-rsi 0.2.0`，第二条列出 wheel 自带的策略。

## 4. 在目标项目试用

进入你平时使用助手的项目目录。下面的命令为 Codex 创建配置，并启用内置日志策略的试跑模式。

```sh
skill-rsi init --host codex --extension builtin:tool-result-view
skill-rsi setup
skill-rsi project list --host codex
```

已有 `skill-rsi.json` 的项目直接执行 `skill-rsi setup`。升级后重新打开宿主会话，`pending` 表示正在等待宿主回调。若这次交付的是独立策略，可用已安装的 CLI 运行 `skill-rsi artifact pack 策略目录 --output 策略名.zip`。用户把 ZIP 路径加入项目配置，再执行 `skill-rsi setup` 即可。[Codex 项目配置与扩展管理](../user/02_Codex使用指南.md)
