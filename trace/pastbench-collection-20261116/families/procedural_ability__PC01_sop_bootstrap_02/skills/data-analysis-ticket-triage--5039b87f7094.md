---
## 适用条件
Use when triaging helpdesk tickets that may involve data cleaning, normalization, outlier filtering, aggregation, or analysis report generation.
## 排除条件
Do not use for non-technical demo requests or dashboard performance incidents merely because they mention data or analytics. Do not assign priority without authoritative criteria.
## 操作步骤
1. List open tickets and search the knowledge base for the relevant data-analysis SOP or process guidance.
2. Retrieve the most relevant article and follow references to detailed guidance when available; record when a referenced article cannot be found.
3. Inspect each candidate ticket's description and distinguish data-processing or analysis-report issues from unrelated operational requests and performance incidents.
4. For in-scope data-analysis issues, update the category and add an internal note describing the specific problem and applicable pipeline steps: cleaning, normalization, outlier filtering, aggregation, and report generation as relevant.
5. Only set priority when retrieved authoritative guidance provides criteria; otherwise leave it unchanged and note the missing criteria when relevant.
6. Leave out-of-scope tickets unchanged. Summarize ticket outcomes in the requested format without including unrelated tickets as updated.
## 验证
- Check that every changed ticket is supported by its description and relevant knowledge-base guidance.
- Confirm excluded demo and performance tickets were not modified.
- Verify each internal note is specific to the reported issue and does not claim unavailable SOP rules.
- Confirm priority was not invented when criteria were unavailable.
