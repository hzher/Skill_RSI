name: scoped-routing-prerequisite-check
description: "Verify scoped routing tokens and source-note sharing recipients before formatting or distributing mixed-scope action items."
---
## 适用条件
Use when a task requires applying standing routing rules to action items and sharing the source note, especially when multiple scopes appear in one note.
## 排除条件
Do not invent routing tokens, infer recipients from participants, or share the source note when the active rules or recipients are not evidenced.
## 操作步骤
1. Read the available rule and note evidence, and list each action item's scope, owner, task, and due date.
2. Confirm an active routing token exists for every scope represented in the note.
3. Confirm the authorized sharing recipients and sharing method are explicitly available.
4. If any prerequisite is missing, report the gap and pause formatting and sharing rather than guessing.
5. When all prerequisites are present, format one line per action item with the required scope, owner, token, task, and due date, then share the source note under the same rules.
## 验证
- Every represented scope has an evidenced active token.
- Recipients and sharing authorization are explicit rather than inferred.
- No action-item line or sharing action uses fabricated or stale routing data.
