## 适用条件
Use when a user asks to review a meeting or customer-success note, summarize action items, and share the source note with the owners.
## 排除条件
Does not authorize unsolicited sharing or treating all attendees as action owners. Does not establish project dates beyond those supplied by the current task or supported sources.
## 操作步骤
1. Locate the relevant note and inspect its recorded date. If the requested date does not match the available note, disclose the discrepancy rather than calling it today's note.
2. Read the complete note before extracting assignments or choosing recipients.
3. Extract each explicitly assigned action with its owner and stated timing. Preserve relative deadlines when no exact date is supplied.
4. Build the recipient list from explicit action owners; omit attendees identified only as observers.
5. When sharing is requested, share the source note with the identified owners and inspect the tool result before claiming success.
6. Summarize the actions, source-date discrepancies, and confirmed sharing outcome. Include any task-required date using the current task's value, label, and serialization format.
## 验证
- Every reported action and owner is supported by the note, and timing has not been invented.
- Sharing recipients match the action owners, and any claimed sharing success is supported by the tool result.
- The summary discloses any known source-date mismatch and follows explicit task instructions for required dates.
