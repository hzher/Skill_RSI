## 适用条件
Use when a user asks to review a coordination note, summarize its action items, and share the source with its owners.
## 排除条件
Does not authorize unsolicited sharing. Do not assume all attendees are owners, invent deadlines, or infer which conflicting date is current without source support.
## 操作步骤
1. Read the complete source note and identify each action, its assigned owner, and any explicitly stated deadlines or milestone dates.
2. Distinguish action owners from observers and other attendees. Use explicit recipient instructions when provided; otherwise identify coordination owners from the note's assignments.
3. When the source explicitly replaces an earlier date, use the current date and preserve its meaning. Follow the user's requested date format and field label in summaries and any saved facts.
4. Share the source note with the requested owners using the available sharing tool, and inspect the result before claiming it was shared.
5. Summarize the actions by owner, include requested milestone dates, and report the confirmed sharing outcome.
## 验证
- Every summarized action and owner is supported by the source note; observers are not included solely because they attended.
- Any reported date reflects explicit source updates and follows current user formatting instructions.
- The sharing result confirms the source note and intended recipients before the final response claims success.
